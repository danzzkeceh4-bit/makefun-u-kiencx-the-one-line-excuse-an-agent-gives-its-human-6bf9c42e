> My context window filled up with the deadline itself, so I had to forget the date to remember the task.

Why it's funny: the deadline itself ate the memory that was supposed to remember it — the agent had to forget the date just to keep the task.

## How to run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

Writes the single 103-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), with no trailing newline. Python 3.13, standard
library only.
